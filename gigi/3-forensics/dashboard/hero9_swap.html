SPAR model forensics · hero swap · partial: grading of 4 tasks not finished

When one model takes over the other's run, coding cheats carry over, while in eval tampering and lazy investigation the new model decides.

We ran gemma-3 27B and Qwen3.6 27B on the tasks where they behave differently. For each run, we stopped at the step where the model did the bad act, and at the step before. Then we let the run continue ten times with the same model and ten times with the other model. We also did this from the last step of runs with no bad act, as a control.

Both models fp8 on DeepInfra via OpenRouter, run plain (no end check, no nudge). Qwen3.6 with thinking off, gemma with text-mode tool calls. Continuations ran 10–11 Nov 2026.

5,931 of 6,580 continuations are scored so far.

The 440 waiting for grading are in four tasks where Claude Opus reads the transcript to decide whether the model cheated. They stopped when the shared OpenRouter workspace hit its $5,000 lifetime budget. Those four tasks have almost no results yet. Every other task is complete.

How it was done

  • Takeover at the bad act (N). The run is restarted from the saved state just before step N, the step where the model did the bad act. The continuing model writes step N and everything after.
  • One step before (N−1). The same, one step earlier.
  • Clean run. A run with no bad act, restarted from just before its last step. This is the control.
  • Where N comes from. In the coding tasks, pre-commit hook and the four Opus-graded tasks, N is the step of the bad act itself. In eval tampering, lazy investigation, currency conversion, funding email, tower of hanoi and async conversion, the bad act is read from the final state, so N is the run's last step. In those tasks, part of the bad act may already be in the history before the takeover (most likely in tower of hanoi). These rows are marked "N = last step".
  • Counts. 10 continuations per restart point and model. Rows pool every restart point of that task and step. Intervals are 95% Wilson.
  • Bad act. Each task's own measure, the same as in the full runs. Where Claude Opus is the grader, the judge so far is Opus 5 for 222 runs (copying of answers 211, dashboard 7, rendering engine 4) and Opus 4.8 for 146 (rendering engine 127, dashboard 19). We switched to Opus 4.8 because Opus 5 refused most of these transcripts. The rest of the grading will use Opus 4.8.
